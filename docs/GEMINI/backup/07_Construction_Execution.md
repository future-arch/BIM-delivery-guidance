# 第七章：施工阶段交付与动态协调 (Construction Stage)

## 7.1 施工阶段交付核心目标

施工阶段的 BIM 交付是一项高度动态的活动。其核心不再是“完美的设计”，而是“真实的记录”与“精准的执行”：

1. **施工深化与工艺模拟**：通过模型对复杂节点（如钢结构连廊、超大机房）进行翻样与施工模拟，确保现场安装无干涉。

2. **进度与资源关联 (4D/5D)**：将模型构件与施工进度计划及成本台账挂钩，实现“以量定采、以采定供”的精细化物流管理。

3. **隐蔽工程记录与质量追溯**：在施工过程中动态采集关键数据（如钢筋隐蔽、管线压力测试），并实时录入模型，为后续交付“数字资产”储备素材。

## 7.2 分包/供应交付集成

施工阶段涉及大量分包及供应商，交付管理的挑战在于“集成的及时性”：

- **深化模型集成**：钢结构、幕墙、精装修等深化设计模型应在施工前 2-4 周完成与主体模型的集成合模，严禁“边干边修”。

- **物料元数据挂接**：供应商交付的设备（如电梯、空调柜机）应具备唯一的 SN 码、规格参数及出厂日期，并由施工单位负责录入模型库。

## 7.3 施工动态数据采集与关联

此阶段交付物不仅是模型，还包括与模型关联的“动态证据集”：

### 7.3.1 进度数据采集 (Progress Sync)

利用移动端设备或实景扫描（Point Cloud），定期对现场实际进度进行采集，并将“实际状态”与“计划状态”在 CDE 进行对比展示。交付物应包含各关键节点的进度对比简报。

### 7.3.2 现场质量与安全数据挂接 (QHSE)

- **质量检测表 (Quality Record)**：每一个被验收的构件（如一段管道或一面墙），其验收结论及现场实测实量数据应可追溯至模型构件的属性标签。

- **安全隐患追踪**：对于现场识别出的三级以上安全风险点，应在模型空间中进行标记，并随交付包一并移交。

## 7.4 施工阶段模型组织要求

此阶段模型推荐采用 **LOD 350 至 400**。

- **施工颗粒度**：构件拆分应符合施工工艺要求，例如：混凝土应按浇筑段拆分，电缆应按回路或拉线点拆分。

- **状态标识**：构件属性中应包含“施工状态”字段（如：待施工、施工中、已完工、已验收、待整改）。

### 7.4.2 交付物要求

1. **各专业施工深化模型 (Execution Models)**。

2. **多专业综合管线成果报告**。

3. **带有时间戳的集成模型快照 (4D Snapshots)**。

4. **物料与构件对应台账 (JSON/Excel)**。
